# AI integration package — planned

This package is reserved for future server-only AI orchestration. It must not be imported into client bundles with API keys.

Initial tools should be read-only, such as `get_sales_summary`, `get_low_stock`, `get_unpaid_invoices`, `get_customer_order_history` (with per-customer access checks), and `get_supplier_purchase_orders`.

Model provider, voice transcription, retention and confirmation policies remain undecided. See `docs/AI_AND_VOICE.md`.
